# WiLauncher

Лаунчер Minecraft: Java Edition для Windows 10/11 x64.

**[Скачать последнюю версию](https://github.com/groznyjalihan9-stack/WiLauncher-releases/releases/latest)**: файл
`WiLauncher_<версия>_x64-setup.exe`. Установка выполняется для текущего пользователя и не требует прав
администратора. Уже установленный WiLauncher обновляется сам и проверяет подпись обновления.

- Все официальные версии Minecraft: от 1.0 до новейших релизов и снапшотов.
- Fabric, Quilt, Forge и NeoForge; моды, ресурспаки, шейдеры и модпаки из Modrinth.
- Сборки с отдельными папками, импорт из Prism/MultiMC и `.mrpack`, резервные копии.
- Аккаунты Offline, Ely.by и Microsoft; 3D-персонаж, скины и плащи.
- Русский и английский интерфейс, тёмная и светлая темы.

Файлы Minecraft в установщик не входят: игра и Java скачиваются с официальных серверов Mojang.
Установщик не подписан сертификатом издателя, поэтому Windows SmartScreen может показать предупреждение.
Чтобы запустить, нажмите «Подробнее» → «Выполнить в любом случае».
